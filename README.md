# cachorros

Este projeto consiste no desenvolvimento de um sistema baseado em Inteligência Artificial capaz de identificar diferentes categorias a partir de imagens. Para o desenvolvimento e treinamento do modelo, foi utilizada a plataforma Teachable Machine, uma ferramenta que permite criar e treinar modelos de aprendizado de máquina de forma acessível e prática.

Durante o treinamento, foram utilizadas diversas imagens de diferentes categorias, permitindo que a Inteligência Artificial aprendesse a identificar características específicas de cada uma delas.

Após o treinamento, o modelo é capaz de analisar uma nova imagem e indicar a categoria que apresenta maior probabilidade de corresponder ao conteúdo apresentado.

O projeto também demonstra que o mesmo conceito pode ser aplicado a diversas finalidades. Com diferentes conjuntos de imagens para treinamento, é possível desenvolver modelos capazes de identificar animais, objetos, plantas e diversas outras categorias. Dessa forma, o Teachable Machine pode ser utilizado como uma ferramenta introdutória para compreender conceitos de Inteligência Artificial e aprendizado de máquina.
